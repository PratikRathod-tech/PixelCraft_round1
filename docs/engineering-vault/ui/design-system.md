# Institutional UI Design System
**Classification: Design Specification**

---

- Primary Background: Obsidian Slate (`#020617`, `#070b12`).
- Surface Panels: Dark Blue Slate (`#0f172a`, `#1e293b`).
- Accent Glow: Cyan (`#00f0ff`, `#06b6d4`).
- Status Indicators: Emerald (`#10b981`), Amber (`#f59e0b`), Red (`#ef4444`).
- Typography: Inter for UI text, JetBrains Mono for accounts, scores, and currency.
