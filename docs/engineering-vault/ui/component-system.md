# Component Library
**Classification: Design Specification**

---

- `MetricCard`: Telemetry cards with title, value, sparkline, and trend pill.
- `AlertCard`: Forensic alert notifications with risk badges.
- `RiskBadge`: Tier pill (`NORMAL`, `SUSPICIOUS`, `MULE_CANDIDATE`, `HIGH_RISK`).
- `InvestigationDrawer`: Right-side slide-over panel for full account dossiers.
