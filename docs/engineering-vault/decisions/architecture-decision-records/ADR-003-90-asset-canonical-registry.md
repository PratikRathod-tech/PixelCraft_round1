# ADR-003: 90-Asset Canonical Registry
**Status: Accepted**  
**Date: October 2026**

## Context
Unstructured asset folders led to 0-byte file loading crashes and inconsistent licensing.

## Decision
Establish an immutable 90-asset registry (31 procedural, 59 GLB) with automated quarantine validation.

## Consequences
- Guaranteed WebGL stability.
- 100% license compliance.
