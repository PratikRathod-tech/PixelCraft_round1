# ADR-001: 2D-First Application Architecture
**Status: Accepted**  
**Date: October 2026**

## Context
Initial prototypes rendered the entire application inside a full-screen 3D canvas, making the platform feel like a video game rather than a financial intelligence workstation.

## Decision
Adopt a 2D-first application shell with dense analytical dashboards and selective embedded 3D spatial visualization.

## Consequences
- Clean FIU compliance experience.
- Standard web accessibility and responsive scaling.
- 3D is used purposefully as an analytical instrument.
