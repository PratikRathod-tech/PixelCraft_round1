# Phase 4 Pre-Audit Report: ChainRank-AML Research → Live Investigation Data Bridge

## Executive Summary
This pre-audit assesses the existing research outputs, data adapters, server architecture, domain types, and 3D visual subsystems across `Mini_project_1/` prior to implementing Phase 4.

The project already contains:
1. **Verified Research Artifacts**: 150,619-node NetworkX MultiDiGraph, 150,619-row MuleTrace metrics (`3.2_mule_metrics.csv`), 22,374 candidate laundering chains (`3.3_candidate_chains.csv`), 74,117 chain transaction edges (`3.3_candidate_chain_edges.csv`), and 13,578 DMLRank ranked accounts (`exp05_hybrid_extension.csv`).
2. **Python Source Adapters** (`CHAINRANK_AML/source_adapters/`): Read-only boundary adapters for MuleTrace, DMLRank, and graph query extraction.
3. **Production Express Backend** (`Pixel/server/`): Live TypeScript backend with CORS, environment configuration, database abstraction, and health probes on port 3001.
4. **Phase 3 3D Spatial Investigation Foundation**: 90-asset canonical registry, 13-component financial environment, $N \le 150$ hard-cap sampling engine, 4-tier risk visual grammar, 9 camera presets, and interactive investigation canvas.
